# Sculra Shared Modules

This workspace contains code, validation functions, database schemas, and global settings that are shared directly between the `frontend` (Next.js) and `backend` (Express).

## Contents

- `types/`: Common TypeScript interfaces, database definitions, DTO formats.
- `utils/`: Reusable validation helpers, standard formatting logic, string filters.
- `config/`: Global variables and subscription tiers schema configuration.
