# Feature: Testing

This module triggers automated test runs and displays interactive live run traces.

## File Structure

- `components/`: TestRunConsole, StepTimeline, LiveVideoFrame.
- `hooks/`: `useTestRunStream`, `useTriggerTest`.
- `services/`: Webhook trigger and REST endpoints.
- `types/`: Test run phases and interaction parameters.
- `utils/`: Grouping steps by status.
