# Feature: Settings

Handles organization limits, integrations, API keys setup, and configuration flags.

## File Structure

- `components/`: APIKeysList, OrgSettingsForm, IntegrationGrid.
- `hooks/`: `useOrgSettings`, `useAPIKeys`.
- `services/`: Fetching and revolving API keys.
- `types/`: Settings configuration mapping schemas.
- `utils/`: API Key prefix checkers.
