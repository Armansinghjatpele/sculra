# Feature: Reports

This module handles report generation, test summaries, and bug details dashboards.

## File Structure

- `components/`: ReportOverviewChart, BugDetailsCard, ReleaseScoreWidget.
- `hooks/`: `useReportsHistory`, `useBugAnalytics`.
- `services/`: Fetching report PDFs and detail payloads.
- `types/`: Report metrics and release scoring.
- `utils/`: Percentage calculations.
