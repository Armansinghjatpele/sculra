# Feature: Dashboard

This module provides the main landing console layout, summarizing system statuses and showing recent activities.

## File Structure

- `components/`: MetricCardsGrid, ActivityFeedList, UsageSummaryBar.
- `hooks/`: `useOverviewMetrics`, `useRecentActivity`.
- `services/`: Fetching analytical overview reports.
- `types/`: Metrics and activity history types.
- `utils/`: Trend calculations.
